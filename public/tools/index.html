The NDIF Ecosystem

A open-source tools ecosystem for transparent and reproducible experimentation on model internals.

Core Tools

NDIF Server

Remote white-box inference

Free remote access to run interventions on the frontier open models. Register and run reproducible experiments with no local hardware required.

Get accessView on GitHub

NNsight

Model introspection library

Write intervention code once to inspect, modify, and customize any Pytorch model's internal computations — locally or on NDIF.

$ pip install nnsight
DocumentationView on GitHub

NNterp

Standardized transformer interface

A unified interface for mechanistic interpretability, extending NNsight with efficient built-in methods and standardized naming.

$ pip install nnterp
DocumentationView on GitHub

NDIF Workbench

Interactive research UI

Explore prompts and steer model behavior in our web interface for interactive interpretability backed by NDIF remote execution.

Open NDIF WorkbenchView on GitHub

NDIF

The National Deep Inference Fabric (NDIF) is supported by a generous grant from the U.S. National Science Foundation. It is developed by a team at Northeastern University in Boston, Massachusetts.

Computing capacity comes from Delta at NCSA, UIUC. The NDIF community is supported in partnership with PIT-UN, a consortium of 63 universities and colleges.
